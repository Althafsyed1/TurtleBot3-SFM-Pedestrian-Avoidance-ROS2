# TurtleBot3-SFM-Pedestrian-Avoidance-ROS2
Custom Social Force Model local planner for TurtleBot3 Burger robot navigating a simulated cafe environment with pedestrians using ROS2 Jazzy. Implemented as a standalone Python node without modifying Nav2. Achieves 75.6% reduction in pedestrian encounters compared to DWB baseline. CPE631-A Stevens Institute of Technology.
